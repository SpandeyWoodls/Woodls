# `woodls setup`

Initialize `~/.woodls/woodls.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
woodls setup
woodls setup --workspace ~/.woodls/workspace
```

To run the wizard via setup:

```bash
woodls setup --wizard
```
